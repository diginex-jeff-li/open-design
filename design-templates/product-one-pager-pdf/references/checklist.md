# product-one-pager-pdf Checklist

Run this after drafting the HTML artifact. All P0 items must pass before emitting.

## P0 — Must pass

- [ ] Exactly one complete HTML artifact is emitted
- [ ] Artifact is designed for one A4 page
- [ ] Required startup fields were respected: design system, brief text, optional hero image, constraints
- [ ] Selected design system is applied as appearance context
- [ ] Product facts come from the brief, not the design system
- [ ] No invented metrics, counts, percentages, awards, or compliance claims
- [ ] Required structural sections are present or explicitly omitted per slot contract
- [ ] Output includes brief PDF export guidance using WeasyPrint
- [ ] The artifact remains a Product 1-pager, not a different document type

## P1 — Should pass

- [ ] Hierarchy reads clearly in scan order
- [ ] Tagline is concise and not overlong
- [ ] Bullet counts fit within layout tolerance
- [ ] Workflow is coherent and semantically ordered
- [ ] Feature list is product-specific rather than generic filler
- [ ] Contact details are either source-backed or approved defaults from a thin variant
- [ ] Hero image behavior matches input (provided / empty / skip)

## P2 — Nice to have

- [ ] Copy is tightened for brevity
- [ ] Visual density feels balanced across sections
- [ ] Benefit statements are concrete rather than fluffy
- [ ] Section titles are clear and non-redundant
